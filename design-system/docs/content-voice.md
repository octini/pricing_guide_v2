# Content voice

Default voice: plain, direct, unhurried. Match the gallery's calm
paper: short sentences, no ornament.

- **Buttons and links:** verb-first, two words or fewer ("Sign in",
  "New draft", "Retry").
- **Headings:** sentence case in prose, eyebrow labels in uppercase
  microcopy only (`Account`, step labels).
- **Empty states:** name the situation, then the next step ("Nothing
  here yet" → action button). Never blame the reader.
- **Error states:** name what failed and what to try ("The request
  failed. Check the details and try again."). Error color reuses the
  accent ramp — the words, not a red hue, carry the meaning.
- **Form help:** one clause, visible under the field; errors replace
  help and name the fix ("Enter a valid email.").
- **Never:** brand copy, third-party product names, or playful
  breakout language in core components. The quarantined breakout voice
  stays behind its flag.
