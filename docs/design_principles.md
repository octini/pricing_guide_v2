# Design Principles — Mistystep Shop System

Direction: The Screen, locked by user 2026-09-09. Structure is generic-clean
Carbon; fantasy lives in tokens, never layout (per n1y.2 pick-one verdict and
n1y.4 destination lock). No token values here — judgment rules only.

1. **Plate Measure — every row shares one fixed invariant rhythm.**
   Why: the eye never re-calibrates across 11,941 rows, so scanning stays fast.

2. **Single Accent Law — one flat accent owns live state and nothing else.**
   Why: if the accent appears only on active filters, the stepped row, and the
   primary action, live state reads instantly and its rarity is the point.

3. **Forward Step — selection brightens and weighs, never boxes.**
   Why: stepping a row forward signals state without chrome, rules, or cards
   that would break the invariant measure.

4. **Fantasy in tokens, never in structure.**
   Why: generic-clean bones stay reusable for sibling surfaces (feats,
   species, character sheets); flavor confined to tokens cannot leak into
   layout.

5. **Weight is a feature.**
   Why: every kilobyte past budget is a regression against the in-session,
   one-handed lookup job on a phone.

6. **Rarity reads as label plus pattern, never color alone.**
   Why: labeled bands with pattern support carry the rarity-ordered sort for
   every viewer, independent of color perception.
