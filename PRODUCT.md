# Product

## Platform

web

## Users

Primary: Dungeon Masters and players of tabletop roleplaying games doing item price lookup. Two confirmed situations: (1) in-session mobile quick-lookup at the table, one-handed, search-first; (2) desktop research between sessions, comparing and filtering across the catalogue. No other audiences confirmed.

## Product Purpose

A fast, searchable web price guide for ~12,000 TTRPG magic items. It exists so DMs and players can find an item's price and key rules facts in seconds, on a phone mid-session or on desktop while planning. Success means a search-first lookup that stays well under the current ~5MB single-file weight (or splits the data payload), with debounced full-text search and filters that reset to page one.

## Positioning

The catalogue depth is the mechanism a neighboring tool could not truthfully copy: 11,941 priced rows generated by this repo's own pipeline (scripts/11_generate_html.py renders data into index.html served from the repo root via Cloudflare Pages at shop.mistystep.net), with rarity-ordered sorting and attunement/price semantics baked into the data. The coming design system is the go-to generic-clean system for future sibling surfaces (feats, species, character sheets); fantasy flavor lives in tokens, not in page structure.

## Operating Context

Workflows: debounced client-side full-text search across name + type + source + key rules text; filters for price-range slider, attunement toggle, rarity, type, source; sort by price/name/rarity; 50 items per rendered page with pagination that resets to page 1 on any filter change; mobile search-first landing with sticky filter bar and tap-row detail sheet; desktop shareable filtered views via URL query params (saved lists explicitly deferred). Pipeline scripts run pre-commit, not in Pages; Pages serves the committed root index.html statically with no build step. Further filter refinements are expected after hands-on use.

## Capabilities and Constraints

Confirmed functionality: client-side search/filter/sort/pagination over the full 11,941-row dataset; rarity ordering; attunement flag; price min/max; sortable columns; URL query-param state for shareable views. Technical constraints: single static page served from repo root (no build config: no wrangler.toml, _headers, or package.json); current index.html ~5MB/536 lines with embedded item JSON and inline script from line 263; load-weight budget well under ~5MB or a split data payload; production branch master; push-to-master auto-publishes via Cloudflare Pages. Terminology: rarity order, attunement, ITEMS_PER_PAGE=50. Explicitly undecided: exact post-hands-on filter refinements; whether the payload splits or shrinks.

## Product Principles

1. Lookup speed outranks catalogue ceremony: search-first, debounced, one-handed on mobile.
2. Generic-clean system, fantasy in tokens: structure stays reusable for sibling surfaces; flavor never leaks into layout.
3. One base, borrowed principles: Carbon structure governs; other systems inform judgment, never tokens.
4. Document first, then tokens: lightweight PRD plus design-principles gate before token work.
5. Weight is a feature: every kilobyte past budget is a regression against the in-session job.
